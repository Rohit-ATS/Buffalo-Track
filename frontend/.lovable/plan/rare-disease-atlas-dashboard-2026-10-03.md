# Rare Disease Atlas dashboard

## Goal

Create a dedicated `/dashboard` experience inspired by the uploaded modular health dashboard, while preserving the Atlas editorial typography, green evidence palette, pencil sketches, and research-first language.

## What I’ll build

- Add a responsive dashboard route with unique search metadata and sitemap inclusion.
- Create a compact top navigation with links to the landing page, dashboard, STXBP1 research, and evidence.
- Build a dense overview using functional controls and cards for mapped conditions, evidence coverage, active collaboration briefs, research activity, and next actions.
- Add an interactive seven-day evidence chart, evidence-tier breakdown, biological-neighbor network, recent receipts, and collaboration queue using existing project claims and sample data.
- Preserve the required “research navigation, not medical advice” disclaimer.
- Add a Dashboard link to the landing page navigation without changing its existing content or layout.

## Visual direction

- Translate the screenshot’s rounded modular grid into off-white and pale green surfaces with dark graphite text.
- Retain DM Serif Display, DM Sans, Caveat, fine borders, hand-drawn annotations, and green linework.
- Use stable card dimensions, restrained motion, and responsive horizontal navigation on smaller screens.

## Verification

- Check `/dashboard` at desktop and mobile sizes.
- Exercise the date-range and evidence-filter controls.
- Confirm there is no horizontal overflow, runtime error, or build failure.
